# LatAvto54

Сайт автомобильных услуг: выкуп, подбор и проверка, автомобили под заказ, автоняня, мойка и трезвый водитель.

## Просмотр

Сайт публикуется через GitHub Pages из ветки main, корневой папки.

## Локальный запуск

Нужен Node.js. Зависимости устанавливать не требуется.

- node serve.mjs — локальный просмотр на http://127.0.0.1:4173
- node check.mjs — проверка страниц, ссылок и ресурсов

## Файлы

index.html — главная. Страницы услуг находятся в соответствующих папках. Общие стили и поведение — assets/site.css и assets/site.js.

Формы подготавливают сообщение для самостоятельной отправки через WhatsApp. Серверная обработка заявок и CRM не подключены. Фотографии являются иллюстрациями услуг. Перед окончательным запуском нужно подтвердить реквизиты и условия. Шрифт Manrope распространяется с файлом лицензии assets/fonts/OFL.txt.
